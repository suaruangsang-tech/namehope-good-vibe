NameHope Good Vibe — Compact Music Player draft

This package is based on the original site archive available in the project files.
Changes:
- Replaces the large visible player card with a small floating play/stop control at the bottom-right.
- Hides the visible track list, video stage, track title, and previous/next controls.
- Keeps the original site's shuffled queue behavior: tracks are played in a randomized queue, without fixed playlist order.
- Keeps the original page layout and social links.

IMPORTANT:
This is a visual/player draft based on the ORIGINAL site archive. It does not include the newer Supabase cloud-admin upload build. Do not deploy this as a replacement for the Supabase Admin Upload version. The same player changes should be merged into that version before final deployment.
